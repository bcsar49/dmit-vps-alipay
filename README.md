## 买完之后：SSH 密钥这事要特别注意

DMIT 默认不支持密码登录，只能用 SSH 密钥——这是新手最常卡住的地方。

VPS 开通后第一次进后台，会弹出下载密钥的提示框。**这个私钥只能下载一次**，关掉就找不回来了，必须立刻点 Download Private Key 保存到本地。

下载下来是个压缩包，解压后 `private_key` 文件夹里的 `id_rsa.pem` 就是你要用的文件。拿 Xshell、FinalShell 或者系统自带的 ssh 命令，用密钥方式连接即可：


ssh -i /path/to/id_rsa.pem root@你的VPS-IP


如果私钥丢了，可以在后台重新生成——旧密钥会失效，服务器上的数据不受影响，但需要重新配一次连接。

## 常见问题

**Q：支付宝付款会有汇率问题吗？**
价格是美元结算，支付时按当时支付宝汇率换算成人民币，和正常境外消费一样。不用额外手续费，就是当日汇率。

**Q：IP 被墙了怎么办？**
每 15 天可以免费换一次 IP，其他情况 5 美元一次。具体规则在官网服务条款的 IP Replacement Policy 章节里有写，购买前建议看一眼确认当前政策。

**Q：新注册的账号能立刻下单吗？**
大部分情况可以，但有时候新账号有几天等待期才能下单。建议提前几天注册好账号，不要想买的时候临时注册。

**Q：只有 Linux，没有 Windows 吗？**
对，DMIT 目前全系只提供 Linux 系统，没有 Windows VPS 选项。

**Q：月付和年付哪个合算？**
如果打算长期用，年付会便宜很多，而且很多优惠码只对季付/年付有效。月付适合先试试，确认线路和性能符合需求再切年付。

**Q：DMIT 会超售吗？**
官方明确不超售。热门套餐经常缺货就是因为这个——他们不会多卖，实际库存上架多少就卖多少。
